- K4 ciphertext is 97 letters (facts/ciphertext.txt) — verified by count; matches Elonka transcript char-for-char (w-lit 2026-10-26) — https://elonka.com/kryptos/ ; Sanborn open letter Aug 2025 "97-character K4 code section" https://www.elonka.com/kryptos/OpenLetterAug2025.html ; Bean 2021 https://ecp.ep.liu.se/index.php/histocrypt/article/view/153
- K1: Vigenere-style (Quagmire III), KRYPTOS-keyed alphabet KRYPTOSABCDEFGHIJLMNQUVWXZ, key PALIMPSEST — https://en.wikipedia.org/wiki/Kryptos ; Gillogly 1999 "KRYPTOS and PALIMPSEST" https://dl.packetstormsecurity.net/crypt/nsa/kryptos/cia-art-jg.htm ; Stein CIA report https://nsarchive2.gwu.edu/NSAEBB/NSAEBB431/docs/intell_ebb_010.PDF . Note: coding chart shows key misspelled PALIMPCEST -> IQLUSION (Wikipedia citing NYT 2010 charts)
- K2: same scheme, key ABSCISSA — same sources as K1. Ending corrected 2006: missing ciphertext S -> plaintext ends ...WESTXLAYERTWO (not WESTIDBYROWS) — https://elonka.com/kryptos/KryptosTimeline.html ; https://www.wired.com/2006/04/typo-confounds-kryptos-sleuths/
- K3: transposition only, 336 letters (Stein: frequencies = English => transposition) — Stein report (above); Gillogly 1999 "three columnar transpositions"; NSA described as keyed columnar transposition in incompletely filled 4x86 matrix (KRYPTOS key) per https://rumkin.com/reference/kryptos/k3/ (secondary). Equivalent public decrypt: write width 21 read cols R->L, then width 28 (rumkin). Plaintext paraphrases Carter, contains DESPARATLY.

- (it22) NSA 2007 summary (DOCID 4145037, p.25-26) on K4: "fairly flat distribution, although there are eight Ks"; "no long repeats, but there is a slight interval 7 property"; the author tried plaintext autokey and ciphertext autokey with no result. NSA 1992 (DOCID 4051151 p.16): "roughness on interval 7"; hypotheses PT-autokey with a high-frequency letter valued 0, and substitution followed by K3-style transposition; neither solved. Slide p.62 shows K4 above a box redacted under (b)(1)/(b)(3): some NSA K4 work stays classified.
- (it22) Zona Motel interview (Kobek): the K4 scraps are "different things … cut up and put together"; the known plaintext is "exactly in the right position"; the text is "exactly the right length". With Sanborn's "five pieces of scrambled texts", the likeliest reading is cut-and-pasted pieces, not a letter-level transposition: the cribs stay positional.
